# Proyectos de Machine Learning

Proyectos de machine learning y visión por computadora que hice en cursos guiados de Coursera. Cada carpeta trae el notebook, un README con los resultados y las librerías que necesitas para correrlo.

| Proyecto | Qué hace | Herramientas | Resultado |
|---|---|---|---|
| [Predicción de cáncer de mama](prediccion-cancer-de-mama/) | Clasifica tumores como benignos o malignos | scikit-learn · pandas · seaborn | 95.1% de exactitud |
| [Predicción de abandono de clientes](prediccion-abandono-clientes/) | Predice qué clientes de una telefónica se van a dar de baja | PySpark · Plotly | AUC de 0.80 |
| [Descripción de imágenes con Gradio](descripcion-de-imagenes-gradio/) | Describe y clasifica imágenes en una app web interactiva | Hugging Face · PyTorch · Gradio | Demo interactiva |

## Cómo correrlos

La forma más fácil es abrirlos en Google Colab con el botón que viene en el README de cada proyecto. Si prefieres correrlos en tu computadora:

```bash
pip install -r requirements.txt
jupyter notebook
```

(Usa el `requirements.txt` que está dentro de la carpeta de cada proyecto.)
